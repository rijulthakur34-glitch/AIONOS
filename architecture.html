SkyKing Airlines — Customer Resolution Agent Assignment 3
System Architecture · AIONOS Agentic AI Factory · Batch 2027 · Exercise date: 23 Sep 2026

Overview

This agent handles airline disruption scenarios for three real customers from the Assignment 3 data pack. It identifies customers, interprets their requests, enforces policy rules, and produces structured reasoning traces for every decision — making the agent fully explainable and auditable.

The system is implemented as a pure HTML/CSS/JS single-page application — no backend, no external APIs, no dependencies. All data is grounded strictly in the data pack.

Key Design Decisions

🧠 Transparent Reasoning
Every agent response produces a structured chain-of-thought: intent detected → policy checked → action allowed or blocked → conclusion. Displayed as an expandable trace in the UI so any decision can be audited step-by-step.
👮 Human-in-the-Loop
The Supervisor Command Centre shows live risk score (0–100), frustration level, turns taken, last policy cited, and a full action log. Supervisors can inject messages directly into any conversation.
🚫 No Hallucination
Every response is grounded strictly in the data pack. The agent never invents policy rules, customer data, or facts. The DATA object is the single source of truth, and every policy response cites its policyId.
😤 Anger Scales Empathy, Not Policy
Frustration detection adjusts the empathy prefix intensity — but never changes the policy decision. An angry customer gets a more empathetic response, but the same entitlements. Agents don't cave under pressure.
⚡ Hard Escalation Triggers
Legal threats, requests for upgrades beyond policy, fare differences above ₹1,500, and requests to process refunds to a different payment method all trigger immediate escalation — no agent discretion allowed.
📊 Risk Scoring
Every agent turn updates a session risk score (0–100) based on actions taken. Issuing entitled compensation reduces risk; denied requests, anger, and escalations increase it. Displayed as a live animated ring in the supervisor panel.
